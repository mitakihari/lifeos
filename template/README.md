# {{owner}}'s LifeOS vault

Private. This is the data half of LifeOS: notes, plans, and the books. The tools live in the public [lifeos](https://github.com/mitakihari/lifeos) repo.

- Open this folder as a vault in **Obsidian**.
- Start with `01 Home.md`.
- In **Claude Code**, run `claude` from this folder. Claude reads `CLAUDE.md` automatically, and the slash commands live in `.claude/commands/`.
- In the **Claude app**, add this folder to the chat with "Add folder" and tell Claude to read `CLAUDE.md`.
- CLI: `python3 _system/bin/lifeos.py --help`
